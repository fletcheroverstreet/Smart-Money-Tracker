The worker

Collect and check

One scheduler, under 10 SEC requests a second

  • Stores an exact copy of every filing before reading it
  • Reads Forms 3, 4, 5 and 144 with versioned parsers
  • Flags values that can't be right: other currencies, ADS ratios, splits, typed totals
  • Names people and companies, using the filers' own signatures
  • Catches up after an outage and fills any day the daily index shows as short

Ingesting twice changes nothing: every write is keyed on the filing.

Postgres + API

One set of counting rules

FastAPI over Postgres 18

  • Every total counts open-market trades, one copy per trade
  • Flagged values are listed, and left out of dollar totals
  • Each trade keeps three times: traded, disclosed, on screen
  • A live stream pushes new filings to the page as they load
  • Status reports freshness, speed and what the checks found

A missing number is shown as “–”, never as zero.
